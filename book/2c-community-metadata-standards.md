# 2c. Community Metadata Standards 

## Discipline-Specific Practices 

Some fields of study have developed their own norms and specific guidelines for metadata, including how to abbreviate and name things. These subject-specific practices are called community metadata standards, sometimes called schemas. 

## Explore the standards for your field 
Find if there is acommunity metadata standards related or close to your research project:   

- Visit the <a href="https://dcc.ac.uk/guidance/standards/metadata" target="_blank"> Digital Curation Centre </a> to see an overview of community metadata standards categorized by discipline. Click on the category that relates to your research project. Scan the list of metadata standards and see which ones best match your project.    

- Visit <a href="https://fairsharing.org/search/" target="_blank"> Fairsharing.org </a> and enter the topic(s) of your research into the search window.  If available, FAIRsharing will show you community metadata standards connected to those topics.  

- Does your project involve code or software? If yes, visit the <a href="https://codemeta.github.io/codemeta-generator/" target="_blank"> CodeMeta generator </a>. This tool provides a metadata template for code/software and allows you to create a json file from it to add it to your code repository.
