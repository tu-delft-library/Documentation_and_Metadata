# 1b. Documentation Strategies  

While planning your project, you should define which strategy and/or tool you will use to document different stages of the research cycle. Here, we'll introduce and describe a variety of documentation strategies. There isn't a single right way to do documentation because the selected documentation tools and practices need to **fit the project and process**. We'll look at key questions and types of documentation that correspond to important stages of the research project cycle: data collection, processing/analysis and code and scripts.
