# 1b. Documentation Strategies  

While planning your project, you should define which strategy and/or tool you will use to document different stages of the research and/or design cycle. Here, we'll introduce and describe a variety of documentation strategies that hold for different types of data and research objects. There isn't a single right way to do documentation because the selected documentation tools and practices need to **fit the research object and project processes**. We'll look at key questions and types of documentation that correspond to important stages of the project cycle: the collection of data and research objects, processing/analysis and code and scripts.
