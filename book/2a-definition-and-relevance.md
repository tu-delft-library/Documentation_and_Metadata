# 2a. Definition & Relevance 

## Defining metadata

Metadata is commonly referred to as “data about data.” Metadata gives information about the key attributes of a research object. 

Examples of **common metadata fields** include:  
- the format
- which variables it contains
- when the research object was collected and/or by whom
- the version
- the instrument or software used  

It's important to note that **well-structured metadata can be read by humans and also by *machines***. Also, the creation of metadata should be ongoing throughout a project: it needs to be recorded and updated as research objects are created, processed, and connected to other outputs.  

 

## Relevance 

Metadata is a key element of findable and reusable research projects because:  

- Metadata improves the **searchability and findability** of research objects by providing relevant description and contextual information.  

- Metadata supports **discoverability, indexing and reuse** for research objects because it can be indexed and used as search terms.  

- Machine-readable metadata makes it possible to repositories to **index and catalogue** research objects, which makes them easier for others to find.  

In short, metadata offers immediate insights into what's included in a research object so that a researcher can determine if it's going to be (re)useful or not.
